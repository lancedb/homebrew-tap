# LanceDB Homebrew tap

Install the LanceDB CLI and check its version:

```sh
brew install lancedb/tap/lancedb
lancedb --version
```

The release provides binaries for Apple Silicon on macOS 14 or later and for ARM64 and x86-64 on Linux with glibc 2.28 or later. Linux x86-64 requires AVX2, FMA, and F16C.
